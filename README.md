## 📌 Visão Geral
Website pessoal e portal de projetos hospedado diretamente através do **GitHub Pages** no domínio público [lucas4nt0s.github.io](https://lucas4nt0s.github.io).

O site atua como ponto central de apresentação pessoal, agrupando links para redes profissionais, projetos acadêmicos e de extensão desenvolvidos no IFSULDEMINAS, além de conter a versão web jogável do projeto **ASMD (Jogo de Matemática e Aritmética)**.

---

## 🚀 Funcionalidades Principais
- 🧭 **Navegação Responsiva**: Menu de navegação fluido com animação mobile desenvolvida em classe orientada a objetos (`MobileNavbar`).
- 🎮 **Jogo Educacional ASMD Integrado**: Versão interativa web do jogo de operações matemáticas (Adição, Subtração, Multiplicação e Divisão) com pontuação em tempo real para múltiplos jogadores.
- 📱 **Design Multiplataforma**: Adaptação para dispositivos móveis, tablets e monitores widescreen.
- 📬 **Área de Contato e Conexões**: Links diretos para LinkedIn, GitHub e canais acadêmicos.

---

## 🛠️ Tecnologias e Ferramentas
- **Linguagens**: HTML5, CSS3, JavaScript (ES6+)
- **Hospedagem & CI/CD**: GitHub Pages
- **Paradigma de UI**: JavaScript com classes para controle de componentes visuais
